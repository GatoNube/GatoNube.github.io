    说明与建议

    信任评分怎么来的? 本站不提供"真实分数",而是把你这次检测到的公开信号 (出口地区是否在支持名单内、是否被标记为 VPN / 代理 / Tor / 中继 / 机房、 ASN 类型、是否 IPv6、Claude 各域名是否可达)按固定权重累加,满分 100。 每一笔加减分都列在上面,可以自己核对。

    几个常见结论:

    • 机房 IP + 支持地区 —— 多数云服务器属此类。评分不低,但访问 Claude 常被要求验证。
    • VPN / 代理标记 —— 被识别后更容易触发人机验证甚至拒绝服务。
    • IPv6 出口 —— Claude Code 官方建议走 IPv4,IPv6 偶发连接问题。
    • 时区与 IP 不一致 —— 浏览器时区若和出口 IP 所在时区对不上,是常见的关联风险信号,建议保持一致。

    想要更权威的判定(含住宅/机房标注、历史记录、更细的指纹比对),可以参考 ip.net.coffee 的同类检测。Claude 支持地区的完整官方名单请以 Anthropic 官方说明 为准 —— 本站内置的是高置信度子集,可能滞后。
