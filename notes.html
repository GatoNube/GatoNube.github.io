Gotchas

GitHub Pages 用户主页 vs 项目页

用户主页的仓库名必须精确等于 <用户名>.github.io, 网址就是 https://用户名.github.io;项目页则是任意仓库名, 网址多一层 /仓库名。用户主页仓库创建后 GitHub 会自动启用 Pages,不用手动开。

部署"卡住"其实是在排队

推送后如果访问 404,不一定是失败。Pages 的 build 作业通常十几秒完成, 但 deploy 作业可能在运行器队列里等几十分钟。 用 gh run list 看状态比反复刷新网页更靠谱。

自定义 404 返回 404 状态码是正常的

上传 404.html 后,访问不存在的路径会渲染它,但 HTTP 状态码仍是 404 —— 这是规范行为,能让搜索引擎正确识别,同时给用户看到友好的页面。
